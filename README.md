
# Hermathena Documentation

Documentação oficial do **Projeto Hermathena – Comunicação Multimídia do Radiotelescópio BINGO**.

Este repositório utiliza **MyST Markdown** para gerar:

- 📄 **PDF institucional**
- 🌐 **Site navegável**
- 📊 Documentação viva do projeto

## Instalação

```bash
pip install mystmd
```

## Build do site

```bash
myst build
```

## Gerar PDF

```bash
myst build --pdf
```

O PDF será gerado em:

```
_build/pdf/hermathena.pdf
```
